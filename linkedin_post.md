## 📊 Project Overview
Built a comprehensive investment chatbot ecosystem that provides real-time mutual fund data and personalized investment assistance through an intuitive web interface.

### 🤖 **Smart Chatbot System**
- **Natural Language Processing**: Understands complex investment queries
- **Real-Time Data Integration**: Live NAV, SIP, and fund metrics
- **Multi-Fund Coverage**: 4 ICICI Prudential funds with complete data
- **Intelligent Responses**: Context-aware answers about investments

### 🌐 **Full-Stack Web Application**
- **Interactive Website**: Professional Groww-inspired design
- **Embedded Chatbot**: Toggle-based chat integration
- **Responsive UI**: Modern, user-friendly interface
- **Real-Time Updates**: Live data fetching and display

### 📈 **Automated Data Pipeline**
- **Daily Scheduler**: Automated fund data collection
